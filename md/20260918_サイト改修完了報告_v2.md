## フェーズ1: TOPページ追加強化

### 修正ファイル
`00_top.html`

### 変更内容

#### 1. フロー矢印（01〜06ステップ）の重なりバグ修正
- **Before**: `::after` 疑似要素を `border-top + border-right` のシェブロン型で実装 → 隣のカードに重なる
- **After**: solid triangle（CSS border trick）に変更。`right: -14px; top: 50%` で隣カードに干渉しない位置に配置

```css
[data-steps="1"] > div:not(:last-child)::after {
  border-top: 9px solid transparent;
  border-bottom: 9px solid transparent;
  border-left: 13px solid #FFAF04;
  right: -14px;
  top: 50%;
  transform: translateY(-50%);
}
```

#### 2. SVGウェーブ区切りの強化
- 高さ: `56px → 100px`
- パス形状: 単純な山/谷 → **複数ピークの不規則な波形**（よりダイナミック）

#### 3. ヒーローセクションにグリッドオーバーレイ追加
- ゴールド微細グリッド（`rgba(255,175,4,0.04)`、60px間隔）で奥行き感を演出

#### 4. Issuesセクション（03）に斜めストライプ背景
- `repeating-linear-gradient(135deg)` でエッジ感を追加
- 内コンテナに `z-index:1` を付与し可読性を維持

#### 5. AI Drivenセクション（04）背景強化
- ラジアルグラデーションをデュアル化（左上 + 右下の2点配置）
- ゴールド発光感を強化

#### 6. `FROIDE` ウォーターマーク修正
- 誤記 `FREUDEGIZMO` → 正しい `FROIDE` に修正
- opacity: `0.03 → 0.06`、フォントサイズ拡大

#### 7. DQC（DELIVERY / QUALITY / COST）カード強化
- 背景: `rgba(255,255,255,0.04)` → `rgba(255,175,4,0.06)`（ゴールド微発光）
- 右下に幽霊数字（01 / 02 / 03）を追加（エディトリアル感）
- アイコンサイズ: `22px → 26px`
- 文字スペーシング強化

## フェーズ2: 全サブページへのデザイン適用

### 方針
- TOPと「同じ」にならないよう、各ページにコンセプトと固有の演出を付与
- 実装手法: 各ファイルの `</head>` 直前に `<style>` ブロックを注入
- 既存のインラインスタイルは維持し、`!important` で上書き
